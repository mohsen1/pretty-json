BigInt Support Test

This page tests the BigInt support in the pretty-json custom element. Large integers (beyond JavaScript's safe integer range of ±2^53) should be preserved exactly as written.

Test 1: Simple BigInt

{"bigInt": 3028151228586612802, "normal": 42}

Expected: bigInt should be 3028151228586612802 (not 3028151228586612700)

{"bigInt": 3028151228586612802, "normal": 42}

Test 2: Multiple BigInts

{"bigInt1": 9007199254740992, "bigInt2": 3028151228586612802, "normal": 100}

Expected: Both bigInt1 and bigInt2 should be preserved exactly

{"bigInt1": 9007199254740992, "bigInt2": 3028151228586612802, "normal": 100}

Test 3: BigInt in Array

[3028151228586612802, 42, 9007199254740992]

Expected: Large integers in arrays should also be preserved

[3028151228586612802, 42, 9007199254740992]

Test 4: Nested BigInt

{"nested": {"bigInt": 3028151228586612802}}

Expected: Nested big integers should be preserved

{"nested": {"bigInt": 3028151228586612802}}

Test 5: Safe Integers

{"safeInt": 42, "maxSafe": 9007199254740991}

Expected: Safe integers should remain as regular numbers

{"safeInt": 42, "maxSafe": 9007199254740991}
